Variables

Variables are containers for storing data values. In JavaScript, you declare variables using `var`, `let`, or `const`.

  • `var`: Historically used, function-scoped, and can be re-declared and re-assigned.
  • `let`: Block-scoped, can be re-assigned but not re-declared in the same scope.
  • `const`: Block-scoped, cannot be re-assigned or re-declared after initial assignment.


// Using var
var greeting = "Hello";
greeting = "Hi"; // Re-assigned
var greeting = "Hey"; // Re-declared (not recommended)

// Using let
let count = 10;
count = 20; // Re-assigned
// let count = 30; // Error: Cannot re-declare block-scoped variable

// Using const
const PI = 3.14159;
// PI = 3.0; // Error: Assignment to constant variable
const user = { name: "Alice" };
user.name = "Bob"; // Object properties can be changed, but the reference cannot

It's generally recommended to use `const` by default, and `let` if you know the variable needs to be re-assigned. Avoid `var` in modern JavaScript development.

Data Types

JavaScript has several built-in data types that categorize the kind of values a variable can hold. These can be broadly divided into primitive and non-primitive (object) types.

Primitive Data Types:

  • String: Represents textual data (e.g., `"Hello, world!"`).
  • Number: Represents both integer and floating-point numbers (e.g., `10`, `3.14`).
  • BigInt: Represents whole numbers larger than `2^53 - 1`.
  • Boolean: Represents a logical entity and can have two values: `true` or `false`.
  • Undefined: Represents a variable that has been declared but not yet assigned a value.
  • Null: Represents the intentional absence of any object value.
  • Symbol: Represents a unique identifier.

Non-Primitive Data Type:

  • Object: A complex data type that allows you to store collections of data. This includes arrays, functions, and plain objects.

let name = "John"; // String
let age = 30; // Number
let isStudent = true; // Boolean
let score; // Undefined
let car = null; // Null
let id = Symbol('id'); // Symbol

let person = {
    firstName: "Jane",
    lastName: "Doe"
}; // Object

Understanding data types is crucial for performing correct operations and avoiding unexpected behavior in your JavaScript code.

Operators

Operators in JavaScript are symbols that perform operations on one or more operands. They can be categorized into arithmetic, assignment, comparison, logical, and bitwise operators.

Common Operators:

  • Arithmetic: `+`, `-`, `*`, `/`, `%` (modulus), `**` (exponentiation)
  • Assignment: `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`
  • Comparison: `==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`
  • Logical: `&&` (AND), `||` (OR), `!` (NOT)

let x = 10;
let y = 5;
let sum = x + y; // Arithmetic: 15
x += 5; // Assignment: x is now 15
let isEqual = (x === y); // Comparison: false
let isTrue = (sum > 10 && isEqual === false); // Logical: true

Operators are essential for performing calculations, making decisions, and manipulating data in your programs.

Comments

Comments are non-executable lines of code used to explain the code, making it more readable and understandable for developers. JavaScript supports single-line and multi-line comments.

Types of Comments:

  • Single-line comments: Start with `//` and comment out the rest of the line.
  • Multi-line comments: Start with `/*` and end with `*/`, commenting out all text between them.

// This is a single-line comment

/*
This is a multi-line comment.
It can span across multiple lines.
*/
let data = 100; // This comments on the 'data' variable

Use comments effectively to document your code, explain complex logic, or temporarily disable code during debugging.

Statements

A JavaScript statement is a command to be executed by the web browser. Most JavaScript statements end with a semicolon (`;`).

Examples of Statements:

  • Variable declarations: `let x = 5;`
  • Assignment statements: `x = x + 1;`
  • Function calls: `console.log("Hello");`
  • Conditional statements: `if (x > 0) { ... }`
  • Loop statements: `for (let i = 0; i < 5; i++) { ... }`

let message = "Hello World"; // Variable declaration and assignment
console.log(message);        // Function call
if (message.length > 5) {    // Conditional statement
    console.log("Long message");
}

Statements form the backbone of JavaScript programs, defining the actions and logic.

Conditionals

Conditional statements allow you to execute different blocks of code based on whether a specified condition is true or false. The most common conditional statements are `if`, `else if`, and `else`.

If-Else If-Else Structure:


let temperature = 25;

if (temperature > 30) {
    console.log("It's hot!");
} else if (temperature > 20) {
    console.log("It's warm.");
} else {
    console.log("It's cool.");
}

Conditional statements are crucial for creating dynamic and responsive programs that can adapt to different scenarios.

Loops

Loops are used to repeatedly execute a block of code as long as a certain condition is met. Common loop types include `for`, `while`, `do...while`, `for...in`, and `for...of`.

For Loop Example:


for (let i = 0; i < 5; i++) {
    console.log("Iteration " + i);
}
// Output:
// Iteration 0
// Iteration 1
// Iteration 2
// Iteration 3
// Iteration 4

Loops are essential for automating repetitive tasks and iterating over collections of data.

Functions

Functions are blocks of code designed to perform a particular task. They are reusable and can be called multiple times throughout your program.

Function Declaration:


function greet(name) {
    return "Hello, " + name + "!";
}
console.log(greet("Alice")); // Output: Hello, Alice!

Function Expression:


const add = function(a, b) {
    return a + b;
};
console.log(add(5, 3)); // Output: 8

Arrow Functions (ES6):


const multiply = (a, b) => a * b;
console.log(multiply(4, 2)); // Output: 8

const sayHi = () => {
    console.log("Hi there!");
};
sayHi(); // Output: Hi there!

Functions are fundamental to structuring and organizing your JavaScript code, promoting reusability and modularity.

Arrow Functions

Introduced in ES6, arrow functions provide a more concise syntax for writing function expressions. They also handle the `this` keyword differently than traditional functions. 


// Traditional function
const addTraditional = function(a, b) {
    return a + b;
};

// Arrow function
const addArrow = (a, b) => a + b;

console.log(addTraditional(2, 3)); // 5
console.log(addArrow(2, 3));      // 5

Arrow functions are often preferred for their brevity and for maintaining the lexical `this` context.

Variable Scope

Scope defines the accessibility of variables, functions, and objects in some particular part of your code during runtime. JavaScript has global scope, function scope, and block scope (with `let` and `const`). 


let globalVar = "I'm global";

function exampleScope() {
    let functionVar = "I'm function-scoped";
    if (true) {
        let blockVar = "I'm block-scoped";
        console.log(blockVar); // Accessible
    }
    // console.log(blockVar); // Error: blockVar is not defined
    console.log(functionVar); // Accessible
}
exampleScope();
console.log(globalVar); // Accessible
// console.log(functionVar); // Error: functionVar is not defined

Understanding scope is critical for preventing naming conflicts and writing predictable code.

Hoisting

Hoisting is a JavaScript mechanism where variable and function declarations are moved to the top of their containing scope during the compilation phase, before code execution. 


console.log(myVariable); // Output: undefined (var is hoisted)
var myVariable = 5;

console.log(myFunction()); // Output: "Hello from function"
function myFunction() {
    return "Hello from function";
}

// console.log(myLetVariable); // Error: Cannot access 'myLetVariable' before initialization (let/const are not hoisted in the same way)
let myLetVariable = 10;

While declarations are hoisted, initializations are not. `let` and `const` declarations are also hoisted but are in a "temporal dead zone" until initialized.

Objects

Objects in JavaScript are collections of key-value pairs, where keys are strings (or Symbols) and values can be any data type, including other objects or functions. They are fundamental for representing structured data. 


const person = {
    firstName: "John",
    lastName: "Doe",
    age: 30,
    isStudent: false,
    greet: function() {
        return "Hello, my name is " + this.firstName;
    }
};

console.log(person.firstName); // Access property: "John"
console.log(person["age"]);    // Access property: 30
console.log(person.greet());   // Call method: "Hello, my name is John"

person.age = 31; // Modify property
person.city = "New York"; // Add new property

Objects are versatile and widely used for data modeling and organizing related functionalities.

Arrays

Arrays are ordered, zero-indexed collections of data. They can hold values of any data type and are dynamic in size. 


const fruits = ["Apple", "Banana", "Cherry"];

console.log(fruits[0]); // Access element: "Apple"
console.log(fruits.length); // Get length: 3

fruits.push("Date"); // Add element to end
console.log(fruits); // ["Apple", "Banana", "Cherry", "Date"]

fruits.pop(); // Remove last element
console.log(fruits); // ["Apple", "Banana", "Cherry"]

fruits[1] = "Blueberry"; // Modify element
console.log(fruits); // ["Apple", "Blueberry", "Cherry"]

Arrays provide powerful methods for manipulating and iterating over lists of data.

Strings

Strings are immutable sequences of characters used to represent text. They can be created using single quotes, double quotes, or backticks (for template literals). 


let singleQuote = 'Hello';
let doubleQuote = "World";
let templateLiteral = `The ${singleQuote} ${doubleQuote}!`; // ES6 template literal

console.log(templateLiteral); // "The Hello World!"
console.log(templateLiteral.length); // 16
console.log(templateLiteral.toUpperCase()); // "THE HELLO WORLD!"

JavaScript provides numerous built-in methods for manipulating strings, such as `length`, `toUpperCase()`, `toLowerCase()`, `indexOf()`, `slice()`, and `replace()`.

Substring

The `substring()` method extracts characters from a string, between two specified indices, and returns the new sub-string. 


let text = "JavaScript";
let part1 = text.substring(0, 4); // "Java" (characters from index 0 up to, but not including, 4)
let part2 = text.substring(4);    // "Script" (characters from index 4 to the end)

console.log(part1);
console.log(part2);

`substring()` treats its arguments as `start` and `end` indices, swapping them if `start` is greater than `end`. It also handles negative arguments as 0.

Number Methods

JavaScript's `Number` object provides various methods for working with numbers, including formatting, converting, and checking properties.

Examples:

  • `toFixed(digits)`: Formats a number with a specified number of digits after the decimal point.
  • `toPrecision(precision)`: Formats a number to a specified length.
  • `toString()`: Converts a number to a string.
  • `isNaN()`: Checks if a value is `NaN` (Not-a-Number).

let num = 123.456;
console.log(num.toFixed(2));    // "123.46"
console.log(num.toPrecision(4)); // "123.5"
console.log(num.toString());    // "123.456"

let notANumber = parseInt("hello");
console.log(isNaN(notANumber)); // true

These methods are useful for data presentation and validation.

Dates

The JavaScript `Date` object is used to work with dates and times. You can create new `Date` objects, get various components of a date (year, month, day, hour, minute, second), and format them. 


const now = new Date();
console.log(now); // Current date and time

const specificDate = new Date("2025-07-25T10:00:00Z");
console.log(specificDate.getFullYear()); // 2025
console.log(specificDate.getMonth());    // 6 (July is 0-indexed)
console.log(specificDate.getDate());     // 25

console.log(now.toLocaleDateString()); // Formatted date string (e.g., "7/25/2025")
console.log(now.toLocaleTimeString()); // Formatted time string (e.g., "10:00:00 AM")

Working with dates often involves handling time zones and different date formats, which the `Date` object and its methods help manage.

Methods

In JavaScript, a method is a function that is a property of an object. Methods are actions that can be performed on objects, allowing them to exhibit behavior. 


const car = {
    make: "Toyota",
    model: "Camry",
    start: function() { // This is a method
        console.log("Engine started!");
    },
    stop() { // Shorthand method syntax (ES6)
        console.log("Engine stopped.");
    }
};

car.start(); // Call the start method
car.stop();  // Call the stop method

Methods are crucial for object-oriented programming in JavaScript, enabling objects to encapsulate both data and the functions that operate on that data.

Mutators

Mutator methods are those that change the state or content of the object they are called on. For example, array mutator methods directly modify the array.

Array Mutator Examples:

  • `push()`: Adds one or more elements to the end of an array.
  • `pop()`: Removes the last element from an array.
  • `splice()`: Changes the contents of an array by removing or replacing existing elements and/or adding new elements in place.
  • `sort()`: Sorts the elements of an array in place.

let numbers = [1, 2, 3];
numbers.push(4); // numbers is now [1, 2, 3, 4]
console.log(numbers);

let fruits = ["Banana", "Orange", "Apple"];
fruits.sort(); // fruits is now ["Apple", "Banana", "Orange"]
console.log(fruits);

Be mindful when using mutator methods, as they directly alter the original data structure, which can have side effects if not managed carefully.

Accessors

Accessor methods are those that access or retrieve information from an object without modifying its state. They return a new value or a new data structure.

Array Accessor Examples:

  • `concat()`: Returns a new array by concatenating two or more arrays.
  • `slice()`: Returns a shallow copy of a portion of an array into a new array object.
  • `indexOf()`: Returns the first index at which a given element can be found in the array.
  • `map()`: Creates a new array populated with the results of calling a provided function on every element in the calling array.

let arr1 = [1, 2];
let arr2 = [3, 4];
let newArr = arr1.concat(arr2); // newArr is [1, 2, 3, 4], arr1 remains [1, 2]
console.log(newArr);

let original = ["a", "b", "c", "d"];
let sliced = original.slice(1, 3); // sliced is ["b", "c"], original remains unchanged
console.log(sliced);

Accessor methods are preferred when you need to retrieve data or create new derived data without altering the original source.

Constructors

In JavaScript, a constructor is a special method used to create and initialize an object created within a class. It's called automatically when a new object is instantiated with the `new` keyword. 


class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        return `Hello, my name is ${this.name} and I am ${this.age} years old.`;
    }
}

const alice = new Person("Alice", 30); // Calls the constructor
console.log(alice.greet()); // "Hello, my name is Alice and I am 30 years old."

Constructors are fundamental to object-oriented programming, allowing you to define blueprints for creating multiple objects with similar properties and behaviors.

`this` Keyword

The `this` keyword in JavaScript refers to the object that is currently executing the code. Its value depends on how the function is called.

`this` Context Examples:

  • Global context: `this` refers to the global object (`window` in browsers).
  • Object method: `this` refers to the object itself.
  • Event handler: `this` refers to the element that received the event.
  • Arrow functions: `this` retains the `this` value of the enclosing lexical context.

console.log(this === window); // In global scope: true

const obj = {
    name: "Object",
    greet: function() {
        console.log(`Hello from ${this.name}`); // 'this' refers to obj
    }
};
obj.greet(); // "Hello from Object"

const arrowObj = {
    name: "Arrow Object",
    greet: () => {
        console.log(`Hello from ${this.name}`); // 'this' refers to window (lexical 'this')
    }
};
arrowObj.greet(); // "Hello from " (or "Hello from Window" in browser)

Understanding `this` is crucial for working with objects, classes, and event handling in JavaScript.

Events

Events are actions or occurrences that happen in the system you are programming, which the system tells you about so you can respond to them. In web development, events are triggered by user interactions (e.g., clicks, key presses) or browser actions (e.g., page load).

Common HTML Events:

  • `click`: When an element is clicked.
  • `mouseover`: When the mouse pointer moves over an element.
  • `keydown`: When a keyboard key is pressed down.
  • `load`: When a page or image has finished loading.
  • `submit`: When a form is submitted.

<button id="myButton">Click Me</button>
<script>
    document.getElementById('myButton').addEventListener('click', function() {
        alert('Button clicked!');
    });
</script>

Events are the foundation of interactive web pages, allowing JavaScript to react to user actions and dynamic changes.

Event Handling

Event handling is the process of responding to events triggered by user actions or browser activities. JavaScript provides methods like `addEventListener()` to attach functions (event handlers) to specific events on DOM elements. 


<input type="text" id="myInput">
<p id="output"></p>
<script>
    const myInput = document.getElementById('myInput');
    const output = document.getElementById('output');

    myInput.addEventListener('input', function() {
        output.textContent = "You typed: " + myInput.value;
    });
</script>

Effective event handling is key to building interactive and dynamic user interfaces. It allows you to define what happens when a user clicks a button, types in a field, or performs other actions.

DOM Manipulation

DOM (Document Object Model) manipulation refers to changing the structure, style, or content of a web page using JavaScript. The DOM represents the page as a tree of objects, allowing JavaScript to access and modify elements.

Common DOM Methods:

  • `document.getElementById()`: Selects an element by its ID.
  • `document.querySelector()`: Selects the first element that matches a CSS selector.
  • `element.textContent` / `element.innerHTML`: Get or set the text/HTML content.
  • `element.setAttribute()`: Sets the value of an attribute on the specified element.
  • `document.createElement()`: Creates a new element.
  • `parentNode.appendChild()`: Adds a new child node to an element.

<div id="container"></div>
<script>
    const container = document.getElementById('container');
    const newParagraph = document.createElement('p');
    newParagraph.textContent = "This is a new paragraph added by JavaScript!";
    container.appendChild(newParagraph);
    container.style.backgroundColor = "#e6ffe6"; // Change background
</script>

DOM manipulation is central to creating dynamic and interactive web interfaces, allowing content to change without full page reloads.

jQuery

jQuery is a fast, small, and feature-rich JavaScript library. It simplifies HTML document traversal and manipulation, event handling, animation, and Ajax interactions for rapid web development. While modern JavaScript often provides native alternatives, jQuery is still widely used in many existing projects. 


<!-- Include jQuery library -->
<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.6.0/jquery.min.js"></script>
<div id="myDiv">Hello jQuery!</div>
<script>
    $(document).ready(function() {
        $('#myDiv').css('color', 'blue').hide().fadeIn(1000);
    });
</script>

jQuery's concise syntax and cross-browser compatibility made it incredibly popular for simplifying common web development tasks.

JSON

JSON (JavaScript Object Notation) is a lightweight data-interchange format. It is easy for humans to read and write, and easy for machines to parse and generate. It is based on a subset of the JavaScript programming language and is commonly used for transmitting data between a web application and a server.

JSON Structure:


{
    "name": "Alice",
    "age": 25,
    "isStudent": true,
    "courses": ["Math", "Science"],
    "address": {
        "street": "123 Main St",
        "city": "Anytown"
    }
}

Working with JSON in JavaScript:


const jsonString = '{"name": "Bob", "age": 40}';
const jsonObject = JSON.parse(jsonString); // Convert JSON string to JavaScript object
console.log(jsonObject.name); // "Bob"

const jsObject = { city: "London", population: 9000000 };
const newJsonString = JSON.stringify(jsObject); // Convert JavaScript object to JSON string
console.log(newJsonString); // '{"city":"London","population":9000000}'

`JSON.parse()` and `JSON.stringify()` are built-in JavaScript methods for converting between JSON strings and JavaScript objects.

AJAX

AJAX (Asynchronous JavaScript and XML) is a set of web development techniques using many web technologies on the client-side to create asynchronous web applications. With Ajax, web applications can send and retrieve data from a server asynchronously (in the background) without interfering with the display and behavior of the existing page.

Fetch API Example (Modern AJAX):


// Example using Fetch API to get data
fetch('https://jsonplaceholder.typicode.com/todos/1')
    .then(response => response.json())
    .then(json => console.log(json))
    .catch(error => console.error('Error fetching data:', error));

// Example using async/await with Fetch
async function getUserData() {
    try {
        const response = await fetch('https://api.example.com/users/1');
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error('Failed to fetch user data:', error);
    }
}
// getUserData();

AJAX is crucial for building dynamic web applications that can update parts of a page without a full refresh, providing a smoother user experience. The `fetch` API is the modern way to perform AJAX requests.

Promises

A `Promise` is a JavaScript object that represents the eventual completion (or failure) of an asynchronous operation and its resulting value. Promises provide a cleaner way to handle asynchronous code compared to traditional callbacks (callback hell).

Promise States:

  • `pending`: Initial state, neither fulfilled nor rejected.
  • `fulfilled` (`resolved`): Meaning that the operation completed successfully.
  • `rejected`: Meaning that the operation failed.

const myPromise = new Promise((resolve, reject) => {
    // Simulate an asynchronous operation
    setTimeout(() => {
        const success = true; // Change to false to see rejection
        if (success) {
            resolve("Data fetched successfully!");
        } else {
            reject("Failed to fetch data.");
        }
    }, 2000);
});

myPromise
    .then(message => {
        console.log(message); // "Data fetched successfully!"
    })
    .catch(error => {
        console.error(error); // "Failed to fetch data."
    });

Promises are fundamental for modern asynchronous JavaScript, often used with `fetch` API and `async/await`.

Event Loop

The Event Loop is a crucial part of JavaScript's concurrency model, allowing it to perform non-blocking I/O operations despite JavaScript being single-threaded. It continuously checks the message queue for tasks to execute. 


console.log("Start"); // 1. Executed immediately

setTimeout(() => {
    console.log("Timeout callback"); // 3. Executed after 0ms, but placed in queue
}, 0);

Promise.resolve().then(() => {
    console.log("Promise callback"); // 2. Executed before setTimeout (microtask queue)
});

console.log("End"); // 1. Executed immediately

Understanding the Event Loop is key to comprehending how asynchronous operations like `setTimeout`, `fetch`, and Promises work in JavaScript.

Callbacks

A callback function is a function passed into another function as an argument, which is then invoked inside the outer function to complete some kind of routine or action. Callbacks are a fundamental pattern for asynchronous programming in JavaScript. 


function fetchData(callback) {
    setTimeout(() => {
        const data = "Some data from server";
        callback(data); // Call the callback function with the data
    }, 1000);
}

function processData(data) {
    console.log("Processing: " + data);
}

fetchData(processData); // Pass processData as a callback
// Output after 1 second: "Processing: Some data from server"

While powerful, excessive nesting of callbacks can lead to "callback hell," which is often mitigated by Promises or `async/await`.

Errors

Errors in JavaScript indicate that something unexpected or problematic occurred during the execution of a script. JavaScript provides an `Error` object and various built-in error types (e.g., `TypeError`, `ReferenceError`, `SyntaxError`). 


// Example of a ReferenceError
try {
    console.log(nonExistentVariable);
} catch (error) {
    console.error("Caught an error:", error.name); // "ReferenceError"
    console.error("Message:", error.message);     // "nonExistentVariable is not defined"
}

// Example of a TypeError
try {
    null.f(); // Cannot read properties of null
} catch (error) {
    console.error("Caught an error:", error.name); // "TypeError"
}

Proper error handling is crucial for creating robust applications that can gracefully recover from unexpected issues.

Try/Catch

The `try...catch` statement is used for error handling in JavaScript. It allows you to test a block of code for errors and handle them gracefully without stopping the script's execution. 


function divide(a, b) {
    try {
        if (b === 0) {
            throw new Error("Division by zero is not allowed.");
        }
        return a / b;
    } catch (error) {
        console.error("An error occurred:", error.message);
        return NaN; // Return Not-a-Number on error
    } finally {
        console.log("Division attempt finished."); // Always executes
    }
}

console.log(divide(10, 2)); // Output: 5, "Division attempt finished."
console.log(divide(10, 0)); // Output: "An error occurred: Division by zero is not allowed.", NaN, "Division attempt finished."

The `finally` block (optional) executes regardless of whether an error occurred or was caught, often used for cleanup operations.

Strict Mode

"Strict mode" is a way to opt-in to a restricted variant of JavaScript. It eliminates some JavaScript silent errors by changing them to throw errors, fixes mistakes that make it difficult for JavaScript engines to perform optimizations, and prohibits some syntax likely to be defined in future versions of ECMAScript. 


"use strict"; // Enable strict mode for the entire script or function

// Example 1: Assigning to an undeclared variable (error in strict mode)
try {
    // undeclaredVar = 10; // This would throw a ReferenceError in strict mode
} catch (e) {
    console.error(e.message);
}

// Example 2: Deleting a non-configurable property (error in strict mode)
const obj = {};
Object.defineProperty(obj, 'x', { value: 10, configurable: false });
try {
    // delete obj.x; // This would throw a TypeError in strict mode
} catch (e) {
    console.error(e.message);
}

It's highly recommended to use strict mode for new JavaScript code to catch common coding mistakes and write more secure and optimized applications.

Type Coercion

Type coercion is the automatic or implicit conversion of values from one data type to another (e.g., string to number, number to boolean). This often occurs when operators are used with values of different types. 


// Implicit coercion (JavaScript automatically converts types)
console.log(5 + "5"); // "55" (Number 5 is coerced to string "5")
console.log("10" - 5); // 5 (String "10" is coerced to number 10)
console.log(true == 1); // true (Boolean true is coerced to number 1)
console.log(false == 0); // true (Boolean false is coerced to number 0)

// Explicit coercion (manual conversion)
console.log(Number("100")); // 100
console.log(String(123));   // "123"
console.log(Boolean(0));    // false

While implicit coercion can be convenient, it can also lead to unexpected bugs. Using strict equality (`===`) and explicit type conversions can help avoid these issues.

RegExp

Regular expressions (RegExp) are powerful patterns used to match character combinations in strings. They are used for pattern-matching, searching, and replacing text. 


// Creating a RegExp
const pattern1 = /abc/; // Literal notation
const pattern2 = new RegExp("abc"); // Constructor

// Using RegExp with string methods
let text = "The quick brown fox jumps over the lazy dog.";
let containsFox = /fox/.test(text); // true
let matched = text.match(/o/g); // ["o", "o", "o", "o"] (global match)

console.log(containsFox);
console.log(matched);

// Replacing text
let newText = text.replace(/lazy/, "active");
console.log(newText); // "The quick brown fox jumps over the active dog."

RegExp offers a compact and flexible way to work with text patterns, essential for tasks like form validation and text parsing.

Iterators

Iterators are objects that define a sequence and a return value upon its termination. They provide a standard way to access elements of a collection one by one. Many built-in JavaScript types like Arrays, Strings, Maps, and Sets are iterable. 


const myArray = ['a', 'b', 'c'];
const iterator = myArray[Symbol.iterator]();

console.log(iterator.next()); // { value: 'a', done: false }
console.log(iterator.next()); // { value: 'b', done: false }
console.log(iterator.next()); // { value: 'c', done: false }
console.log(iterator.next()); // { value: undefined, done: true }

// Using for...of loop (uses iterators internally)
for (const item of myArray) {
    console.log(item);
}

Iterators are a foundational concept for understanding how `for...of` loops and other iteration protocols work in JavaScript.

Map

A `Map` object holds key-value pairs and remembers the original insertion order of the keys. Any value (both objects and primitive values) may be used as either a key or a value. 


const myMap = new Map();

myMap.set('name', 'Alice');
myMap.set(1, 'number one');
myMap.set(true, 'boolean true');

console.log(myMap.get('name')); // "Alice"
console.log(myMap.has(1));      // true
console.log(myMap.size);        // 3

myMap.delete('name');
console.log(myMap.has('name')); // false

myMap.forEach((value, key) => {
    console.log(`${key} = ${value}`);
});

`Map` offers better performance for frequent additions and deletions of key-value pairs compared to plain objects, and allows non-string keys.

Sets

A `Set` object is a collection of unique values. Each value can only occur once in a Set. You can add, delete, and check for the presence of elements. 


const mySet = new Set();

mySet.add(1);
mySet.add("hello");
mySet.add(1); // This will not be added as 1 already exists

console.log(mySet.size);      // 2
console.log(mySet.has("hello")); // true

mySet.delete(1);
console.log(mySet.has(1));    // false

mySet.forEach(value => {
    console.log(value);
});
// Output: "hello"

Sets are useful for storing unique items and performing operations like checking for membership or removing duplicates from an array.

Spread Operator

The spread syntax (`...`) allows an iterable (like an array or string) to be expanded in places where zero or more arguments (for function calls) or elements (for array literals) are expected. It can also be used to expand object properties in object literals.

Examples:

  • Copying arrays: `[...arr]`
  • Concatenating arrays: `[...arr1, ...arr2]`
  • Passing arguments to functions: `func(...args)`
  • Copying objects: `{...obj}`
  • Merging objects: `{...obj1, ...obj2}`

const arr1 = [1, 2];
const arr2 = [3, 4];
const combinedArray = [...arr1, ...arr2]; // [1, 2, 3, 4]
console.log(combinedArray);

const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };
const combinedObject = { ...obj1, ...obj2 }; // { a: 1, b: 2, c: 3, d: 4 }
console.log(combinedObject);

function sum(x, y, z) { return x + y + z; }
const numbers = [1, 2, 3];
console.log(sum(...numbers)); // 6

The spread operator is a versatile and powerful feature for non-mutating operations on arrays and objects.

Rest Parameters

The rest parameter syntax (`...`) allows a function to accept an indefinite number of arguments as an array. This is useful when you don't know how many arguments a function will receive. 


function sumAll(...numbers) {
    let total = 0;
    for (const num of numbers) {
        total += num;
    }
    return total;
}

console.log(sumAll(1, 2, 3));       // 6
console.log(sumAll(10, 20, 30, 40)); // 100

function greet(greeting, ...names) {
    return `${greeting} ${names.join(' and ')}!`;
}
console.log(greet("Hello", "Alice", "Bob")); // "Hello Alice and Bob!"

Rest parameters collect remaining arguments into an array, providing a clean way to handle variadic functions.

Closures

A closure is the combination of a function bundled together (enclosed) with references to its surrounding state (the lexical environment). In simpler terms, a closure gives you access to an outer function's scope from an inner function. 


function outerFunction(outerVariable) {
    return function innerFunction(innerVariable) {
        console.log('Outer Variable:', outerVariable);
        console.log('Inner Variable:', innerVariable);
    };
}

const newFunction = outerFunction('I am outside!');
newFunction('I am inside!');
// Output:
// Outer Variable: I am outside!
// Inner Variable: I am inside!

Closures are powerful for creating private variables, maintaining state, and implementing patterns like currying and memoization.

Memoization

Memoization is an optimization technique used to speed up computer programs by caching the results of expensive function calls and returning the cached result when the same inputs occur again. 


function memoizedAddTo80() {
    let cache = {};
    return function(n) {
        if (n in cache) {
            return cache[n];
        } else {
            console.log('Long time operation...');
            cache[n] = n + 80;
            return cache[n];
        }
    }
}

const memoized = memoizedAddTo80();
console.log(memoized(5)); // Long time operation... 85
console.log(memoized(5)); // 85 (from cache)
console.log(memoized(10)); // Long time operation... 90

Memoization is particularly useful for recursive functions or functions that are called frequently with the same arguments.

Modules

JavaScript modules allow you to break down your code into separate, reusable files. They provide a way to encapsulate code, prevent global namespace pollution, and manage dependencies. ES6 introduced native module syntax (`import` and `export`).

`math.js` (Module):


// math.js
export const add = (a, b) => a + b;
export const subtract = (a, b) => a - b;

`app.js` (Using Module):


// app.js
import { add, subtract } from './math.js';

console.log(add(5, 3));     // 8
console.log(subtract(10, 4)); // 6

Modules are essential for building large-scale JavaScript applications, promoting maintainability and organization.

npm

npm (Node Package Manager) is the default package manager for Node.js and the world's largest software registry. It's used to install, manage, and share packages (libraries, frameworks, tools) for JavaScript projects.

Common npm Commands:

  • `npm init`: Initializes a new Node.js project and creates a `package.json` file.
  • `npm install [package-name]`: Installs a package as a dependency.
  • `npm install -g [package-name]`: Installs a package globally.
  • `npm uninstall [package-name]`: Uninstalls a package.
  • `npm start`: Runs the script defined in `package.json` under the "start" key.

# Initialize a new project

# Install a package (e.g., lodash)
npm install lodash

# Run a script defined in package.json

npm is an indispensable tool for modern JavaScript development, providing access to a vast ecosystem of open-source libraries and tools.

Nullish Coalescing

The nullish coalescing operator (`??`) is a logical operator that returns its right-hand side operand when its left-hand side operand is `null` or `undefined`, and otherwise returns its left-hand side operand. It provides a safer way to set default values than the `||` (OR) operator. 


let userSetting = null;
let defaultSetting = "default value";

// Using || (OR) operator - treats 0, '', false as falsy
let finalSettingOR = userSetting || defaultSetting; // "default value"
let zeroValue = 0;
let resultOR = zeroValue || defaultSetting; // "default value" (undesired if 0 is valid)

// Using ?? (Nullish Coalescing) operator - only treats null/undefined as nullish
let finalSettingNullish = userSetting ?? defaultSetting; // "default value"
let resultNullish = zeroValue ?? defaultSetting; // 0 (correctly keeps 0)

console.log(finalSettingOR);
console.log(resultOR);
console.log(finalSettingNullish);
console.log(resultNullish);

The nullish coalescing operator is useful for providing default values only when a variable is strictly `null` or `undefined`, avoiding issues with other falsy values.

Optional Chaining

The optional chaining operator (`?.`) allows you to safely access properties of an object that might be `null` or `undefined` without causing an error. If a property in the chain is `null` or `undefined`, the expression short-circuits and returns `undefined`. 


const user = {
    name: "Charlie",
    address: {
        street: "456 Oak Ave",
        city: "Someville"
    },
    getDetails() {
        return `${this.name} from ${this.address.city}`;
    }
};

const guest = {}; // No address property

console.log(user.address.city);          // "Someville"
console.log(guest.address?.city);        // undefined (no error)
console.log(user.getDetails?.());        // "Charlie from Someville"
console.log(guest.getDetails?.());       // undefined (no error)

Optional chaining significantly simplifies code when dealing with potentially missing properties in nested objects, preventing `TypeError` exceptions.

Polyfill

A polyfill is a piece of code (or a plugin) that provides the functionality of a modern web feature to older browsers that do not natively support it. It allows developers to write modern JavaScript code and ensure it works across a wider range of browsers. 


// Simple polyfill for String.prototype.startsWith (if not natively supported)
if (!String.prototype.startsWith) {
    String.prototype.startsWith = function(searchString, position) {
        position = position || 0;
        return this.substr(position, searchString.length) === searchString;
    };
}

console.log("Hello World".startsWith("Hello")); // true (works even in older browsers with polyfill)

Polyfills are essential for maintaining cross-browser compatibility, especially when using newer JavaScript features that might not be universally supported.

Bitwise Operators

Bitwise operators treat their operands as a set of 32 bits (zeros and ones) and perform operations on them at the bit level. They are less commonly used in general web development but are important for low-level operations, graphics, or specific algorithms.

Common Bitwise Operators:

  • `&` (AND): Sets each bit to 1 if both bits are 1.
  • `|` (OR): Sets each bit to 1 if one of the bits is 1.
  • `^` (XOR): Sets each bit to 1 if only one of the bits is 1.
  • `~` (NOT): Inverts all the bits.
  • `<<` (Left Shift): Shifts bits to the left.
  • `>>` (Right Shift): Shifts bits to the right (signed).
  • `>>>` (Zero-fill Right Shift): Shifts bits to the right (unsigned).

let a = 5;  // 0101 in binary
let b = 3;  // 0011 in binary

console.log(a & b); // 1 (0001 in binary)
console.log(a | b); // 7 (0111 in binary)
console.log(a ^ b); // 6 (0110 in binary)
console.log(~a);    // -6 (inverts bits)
console.log(a << 1); // 10 (1010 in binary)

While powerful, bitwise operations can be complex to understand and debug.

Enums

JavaScript does not have a native `enum` (enumeration) type like some other languages (e.g., TypeScript, C#). However, you can simulate enums using objects or `const` declarations to define a set of named constants.

Simulating Enums with Objects:


const COLORS = {
    RED: 'red',
    GREEN: 'green',
    BLUE: 'blue'
};

function selectColor(color) {
    if (color === COLORS.RED) {
        console.log("Selected Red");
    } else if (color === COLORS.GREEN) {
        console.log("Selected Green");
    } else {
        console.log("Unknown Color");
    }
}

selectColor(COLORS.RED);   // "Selected Red"
selectColor("purple"); // "Unknown Color"

Using objects for enums improves code readability and reduces the chance of typos when working with a predefined set of values.

Requests

In web development, "requests" typically refer to HTTP requests made from the client (browser) to a server to fetch or send data. The modern way to make these requests in JavaScript is using the Fetch API or `XMLHttpRequest` (older).

Fetch API (GET Request):


fetch('https://jsonplaceholder.typicode.com/posts/1')
    .then(response => response.json())
    .then(data => console.log('Fetched data:', data))
    .catch(error => console.error('Error fetching:', error));

Fetch API (POST Request):


fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        title: 'foo',
        body: 'bar',
        userId: 1,
    }),
})
.then(response => response.json())
.then(data => console.log('Posted data:', data))
.catch(error => console.error('Error posting:', error));

Understanding how to make HTTP requests is fundamental for building dynamic web applications that interact with backend services.

Sort

The `sort()` method sorts the elements of an array in place and returns the sorted array. The default sort order is ascending, built upon converting the elements into strings, then comparing their sequences of UTF-16 code units values. For numbers, a custom comparison function is often needed. 


// Default string sort
let fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.sort();
console.log(fruits); // ["Apple", "Banana", "Mango", "Orange"]

// Numeric sort (ascending)
let numbers = [40, 100, 1, 5, 25, 10];
numbers.sort(function(a, b) { return a - b; });
console.log(numbers); // [1, 5, 10, 25, 40, 100]

// Numeric sort (descending)
numbers.sort(function(a, b) { return b - a; });
console.log(numbers); // [100, 40, 25, 10, 5, 1]

Custom comparison functions are essential for sorting arrays of numbers or objects based on specific criteria.

Storage

Web storage (localStorage and sessionStorage) allows web applications to store data locally within the user's browser. Unlike cookies, Web Storage is not sent with every HTTP request, and it has a much larger storage capacity (typically 5MB or more).

`localStorage`:

  • Stores data with no expiration date. Data persists even after the browser is closed.

`sessionStorage`:

  • Stores data for only one session. Data is cleared when the browser tab is closed.

// localStorage example
localStorage.setItem('username', 'Alice'); // Store data
let user = localStorage.getItem('username'); // Retrieve data: "Alice"
console.log(user);
// localStorage.removeItem('username'); // Remove data
// localStorage.clear(); // Clear all localStorage for the origin

// sessionStorage example
sessionStorage.setItem('tempData', 'This is temporary');
let temp = sessionStorage.getItem('tempData');
console.log(temp);

Both `localStorage` and `sessionStorage` store data as key-value pairs, where both keys and values must be strings. Use `JSON.stringify()` and `JSON.parse()` for storing/retrieving objects.

Switch

The `switch` statement is used to perform different actions based on different conditions. It evaluates an expression and executes the code block associated with the matching `case` value. 


let day = new Date().getDay(); // Get current day (0 for Sunday, 1 for Monday, etc.)
let dayName;

switch (day) {
    case 0:
        dayName = "Sunday";
        break;
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break;
    case 4:
        dayName = "Thursday";
        break;
    case 5:
        dayName = "Friday";
        break;
    case 6:
        dayName = "Saturday";
        break;
    default:
        dayName = "Unknown";
}
console.log("Today is " + dayName);

Always use the `break` keyword to exit the `switch` block once a match is found; otherwise, the code will "fall through" to subsequent `case` blocks. The `default` keyword specifies the code to run if there is no case match.

window

The `window` object represents the browser's window and is the global object in client-side JavaScript. All global JavaScript objects, functions, and variables automatically become members of the `window` object. It provides access to browser features and the DOM.

Common `window` properties/methods:

  • `window.document`: Refers to the `document` object (the DOM).
  • `window.location`: Provides information about the current URL.
  • `window.history`: Manages browser history.
  • `window.alert()`: Displays an alert box.
  • `window.setTimeout()`: Executes a function after a specified delay.
  • `window.innerWidth`, `window.innerHeight`: Get viewport dimensions.

console.log("Current URL:", window.location.href);
console.log("Viewport width:", window.innerWidth);

// window.alert("This is a window alert!"); // (Avoid using in production for better UX)

setTimeout(() => {
    console.log("This message appears after 2 seconds.");
}, 2000);

The `window` object is implicitly available, so you often omit `window.` when calling its properties or methods (e.g., `alert()` instead of `window.alert()`).
